User Guide

How to load DSC Setup, connect its data sources and fill in its settings.

1. Load the workflow

In the workflow runner, add a new template using this repository's URL, then select DSC Setup from the templates list.

2. Data sources

  • An EarthRanger connection for the conservancy being set up. The account needs permission to add patrol types, event types and feature groups.
  • Optionally, a connection for a template conservancy (read-only access is enough).

3. Settings

The run form asks for these. Fields with a default can be left as they are.

A run creates straight away: this version has no preview. To see what would be created without changing the site, run DSC Onboarding Check on it first.

Choosing a template

A template only sets how the new setup looks: the event types' form layouts, field titles and descriptions, icons, priorities and geometry, and the patrol type's icon and priority. The fields always come from the shared schema (keys, types, required flags, choice lists, limits and event type values), so the new site passes the check whichever template you pick. The template site is only read.

  • Left empty: Enarau's look, from the copy in the task package.
  • A form that uses other field names: that form falls back to Enarau's layout. For example, Enonkishu's MetaData form uses Transect_ID, Team_members and Number_of_observers. Titles and icons still come from the template.
  • A template without a DSC setup: the missing parts fall back to Enarau's.

The Template row of the setup table says which template was used and what fell back.

The files go to the results folder the runner gives the workflow (ECOSCOPE_WORKFLOWS_RESULTS):

  • dsc_setup.csv, the setup table;
  • dsc_checklist.csv;
  • a .jsonl log of every request made while creating.

5. After the run

  1. Follow What to Do Next.
  2. Add species and team members to the distancecountwildlife_species and distancecountpatrol_teammembers choice lists in EarthRanger. The workflow never creates these.
  3. Once the transects are final, add them as DSC_Transects features named <prefix>_<n>, with a matching choice for each.
  4. Run the workflow again. Only what's still missing is created, and the checklist updates.
