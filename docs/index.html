What it does

StepWhat it does
Connect to EarthRanger
Set Up DSCCreate the Distance Sampling Count setup an EarthRanger site is missing: an event category (if the site has none), the Distance Count patrol type, both event types with their fields and form layouts, the transect choices and the DSC_Transects feature group. Species and team members aren't created; they are set up in EarthRanger.
Count Items Still to CreateThe number of rows whose status is one of `statuses`, e.g. the checks that failed. Rows that describe the run (Site, Run, IDs) have status Info, so they're only counted when Info is asked for.
Fetch TransectsThe site's DSC_Transects features (name and geometry, EPSG:4326), read-only. Empty when there is no group or it has no features yet.
Persist Setup TablePersist dataframe to a file or cloud storage object.
Count Created ItemsThe number of rows whose status is one of `statuses`, e.g. the checks that failed. Rows that describe the run (Site, Run, IDs) have status Info, so they're only counted when Info is asked for.
Still to Create WidgetCreate a single value widget with a single view.
Check DSC SetupCheck that an EarthRanger site has the Distance Sampling Count setup new conservancies need: the Distance Count patrol type, both event types and their fields, the species and transect choice lists, and the DSC_Transects feature group with one correctly named transect per choice. Read-only.
Transect LabelsOne point per transect, on the line, with its name in a `label` column, for a text layer.
Transect Map ViewA map view framing the transects. Takes the transects directly, not in a list, so the step can be skipped when there are none.
Transect Lines LayerCreates a GeoJSON layer definition based on the provided configuration.
Persist ChecklistPersist dataframe to a file or cloud storage object.
Transect Names LayerCreates a text layer definition based on the provided configuration.
Draw Onboarding ProgressAn HTML card showing where the site is in DSC onboarding: one step per stage, ticked when its checks pass, with the current step highlighted. Sites surveyed before the rules show their differences in amber.
Next StepsMarkdown: what this run did, then one plain instruction per failed check (and warnings worth a look), or the next step when nothing is left to fix.
Format ChecklistThe checklist for reading: grouped by area, failures first within each, with a symbol on each status and, when the setup table is given, a This run column (Created, Would create, Already there, …).
Count Failed ChecksThe number of rows whose status is one of `statuses`, e.g. the checks that failed. Rows that describe the run (Site, Run, IDs) have status Info, so they're only counted when Info is asked for.
Count WarningsThe number of rows whose status is one of `statuses`, e.g. the checks that failed. Rows that describe the run (Site, Run, IDs) have status Info, so they're only counted when Info is asked for.
Checks PassingThe share of checks that don't fail, out of those that pass, warn or fail (information isn't counted).
Analysis IDsMarkdown: the two IDs DSC Analysis needs for this site, ready to copy.
