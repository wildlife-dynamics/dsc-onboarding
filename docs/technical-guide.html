Technical Guide

The steps Dsc setup runs, the packages they come from, and how to recompile and test it.

In the order they run. Each step is a task from one of the packages below.

Recompiling

spec.yaml is the source; ecoscope-workflows-dsc-setup-workflow/ is generated from it by wt-compiler.

./dev/recompile.sh --update   # keeps the lock file and bumps VERSION.yaml
./dev/recompile.sh --install  # a new lock file, and the packages installed

Testing

Each case in test-cases.yaml runs the workflow with its settings:

pixi run --manifest-path pixi.toml -e default bash dev/pytest-cli.sh dsc_setup --all
