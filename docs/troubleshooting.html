Troubleshooting

Common issues while configuring, running or changing DSC Setup, and how to resolve them.

Configuration & connections

A data source connection fails or times out

Check the server URL and credentials in the connection, and that you can sign in to the same server in a browser with them. The account needs API access to the data the workflow asks for.

Set Up DSC fails with TypeError: '>=' not supported between instances of 'NoneType' and 'int'

The build has a task package from before the fix that lets Number of transects be left empty. Rebuild ecoscope-workflows-ext-distance-sample-counts and recompile this workflow. Nothing was created on the site: the run stopped before the step began.

Setting up a site

Items are marked Failed and the rest Not run

An error stops the run at the first item that couldn't be created. The checklist row has the error, and the .jsonl log in the results folder has the full response. The most common cause is a 403: the account can't add patrol types, event types or feature groups on the site. Fix the cause and run again; only what's still missing is created.

An item is listed as Exists but differs

The site already has it, but not as the shared schema says (for example a field with another type, or a missing limit). The workflow never edits existing items, so change it in EarthRanger admin, then run again to check.

The Template row says a form "uses other fields" and the built-in layout is used

The template's form for that event type uses other field names than the shared schema, as on sites set up before it (e.g. Enonkishu's Transect_ID). A layout can only be copied when its fields are exactly the schema's, so Enarau's is used. The titles and icons still come from the template. Pick a template set up with the shared schema, or leave the template empty.

Species or team members show as failed

These choice lists are filled in by the site, never by the workflow. Add the species to distancecountwildlife_species and the team to distancecountpatrol_teammembers in EarthRanger, then run again.

The transect map is empty

The DSC_Transects feature group has no features yet. They are added once the transects are final, each named <prefix>_<n>.

I wanted to see what would be created first

This version creates as soon as it runs. Run DSC Onboarding Check on the site first: its failed checks are what DSC Setup would create.

Developing

CI says the generated files differ from the committed ones

Recompile with ./dev/recompile.sh --update and commit the changes in ecoscope-workflows-dsc-setup-workflow/.

CI says VERSION.yaml must be greater than main's

Every change needs a new version. --update bumps it: the minor number when the run form is unchanged, the major number when it changed.

A test case fails in CI but works locally

The CI reads each data source's credentials from the repository's GitHub secrets, named in .github/workflows/test.yml. Add the missing ones under Settings → Secrets and variables → Actions.
