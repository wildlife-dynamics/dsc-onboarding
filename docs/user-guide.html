User Guide

How to load Dsc setup, connect its data sources and fill in its settings.

1. Load the workflow

In the workflow runner, add a new template using this repository's URL, then select Dsc setup from the templates list.

2. Data sources

  • Access to a EarthRanger data source, set up as a connection

3. Settings

The run form asks for these. Fields with a default can be left as they are.
